# Alles Saniert Clone

Statische Nachbildung von `https://www.allessaniert.at/` mit mehreren Seiten:

- `index.html` (Startseite)
- `forestry-work/index.html`
- `about-us/index.html`
- `contact/index.html`

## Lokal starten

Mit Python:

```bash
python -m http.server 8000
```

Dann im Browser öffnen:

`http://localhost:8000/`
